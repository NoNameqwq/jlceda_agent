# EDA Agent 智能助手

嘉立创EDA专业版内置 AI Agent：在侧边栏里用自然语言查询、搭建和修改原理图 / PCB，也可以问答讲解电路。

## 两种模式

- **工程 Agent**：对话归属当前工程。打开工程时自动唤出（可在设置中关闭），切换工程时自动切换到该工程的对话。
- **独立 Agent**：全局对话，不随工程切换，适合问答、选型和跨工程使用。

顶栏左侧的范围按钮可随时切换两种模式。

## 快速开始

1. 在「扩展管理器」中为本扩展勾选 **允许外部交互**（调用模型接口需要）。
2. 菜单「AI 助手」或快捷键 **Alt+A** 打开侧边栏。
3. 设置 → 模型接口：填写 DeepSeek API Key（无需填写地址），或添加任意 OpenAI 兼容接口，点击「检测连接并获取模型」。

## 功能

- 50+ 个 EDA 工具：工程与文档、视图与选择、原理图、PCB、器件库、导出与生产；可调用任意扩展 API。
- 多对话标签、历史、回溯与分叉、上下文自动压缩。
- 权限模式（只读 / 每次询问 / 自动编辑 / 完全访问）与工具级规则。
- 改动面板：查看每处改动的前后差异，逐项或全部撤销。
- 图片、文件、画布截图输入；Markdown、LaTeX、代码高亮、HTML 电路图渲染。
- 明暗主题，Ctrl + 滚轮缩放界面。
- SimulIDE 动态仿真：内置引擎接管仿真会话，Agent 可读取探针数值、控制仿真、离线验证，并能新建自定义仿真元件（如 74HC30）并自动跑真值表。

## SimulIDE 仿真

本扩展内置 SimulIDE WebAssembly 引擎（来自 [eext-simulation-with-simulide](https://github.com/easyeda/eext-simulation-with-simulide)）。

- 设置 → 通用 →「SimulIDE 仿真引擎」：**接管**（默认，由本扩展运行仿真，支持自定义元件）/ 仅观察 / 关闭。
- 选「接管」时请在扩展管理器中**停用官方 SimulIDE 扩展**，避免两个引擎同时响应。
- 自定义元件：Agent 用门级描述或 .sim1 子电路创建元件并测试；在图中放置同引脚数的外壳芯片（如 74HC00）并绑定位号，运行仿真时自动替换。
